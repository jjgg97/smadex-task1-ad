# Task 1 — Royal Match Mobile Ad (Carousel)

This folder contains a responsive, accessible mobile ad built from the provided basic carousel.

## Files
- `index.html` — structure & content
- `styles.css` — responsive styles (portrait & landscape), brand-inspired look
- `script.js` — auto-slide (every 3s), swipe navigation, dots state, pause on tab hidden
- `assets/` — put your images here:
  - `logo.png`
  - `slide1.jpg`, `slide2.jpg`, `slide3.jpg`

## How to run
Just open `index.html` in your browser. Use DevTools device toolbar to test portrait/landscape.

## Notes
- **Auto-slide**: 3 seconds per slide; pauses/resumes on visibility change and after swipe/tap.
- **Responsiveness**: Portrait uses a compact, high-contrast card; Landscape switches to split layout with the carousel on the left and CTA on the right.
- **Accessibility**: ARIA labels, semantic roles, focusable dots, reduced-motion friendly.
- **Brand feel**: Deep royal blue background, warm gold CTA, soft inner borders and shadows to match a premium puzzle game vibe.

Replace assets with Royal Match visuals you provide for final polish.
